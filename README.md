# DUSTLINE — Godot 4.7 移植版

CS 风格战术射击游戏 **Dustline**（Unity 版，github.com/mmsx4717/dustline）到 **Godot 4.7** 的移植与增强。

## 快速开始

- **Windows**: 解压后运行 `DUSTLINE.exe`
- **Linux**: `chmod +x DUSTLINE.x86_64 && ./DUSTLINE.x86_64`
- 从源码运行: 用 Godot 4.7.2 打开 `project.godot` 按 F5

## 三种模式

| 模式 | 说明 |
|------|------|
| 拆弹模式 | 5v5，购买经济，下包/拆包，先胜 16 回合（CS 规则） |
| 团队死斗 | 5v5，5 秒重生，先到 40 杀 |
| 波次生存 | 无尽波次，敌人逐波增强 |

## 操作

WASD 移动 · Shift 静步 · 空格跳跃 · C/Ctrl 蹲伏 · 左键开火 · 右键瞄准/开镜 · R 换弹 · B 购买菜单（冻结时间） · Tab 计分板 · 1/2/3 切枪 · 4 循环投掷物 · G 放包 · E 下包/拆包/引信

## 移植内容（来自反编译 Dustline.Core / Dustline.Runtime）

- **41 把武器完整数据表**：伤害/护甲比/射速/精准度/后坐力种子/价格/击杀奖励（源 `SourceWeaponData.cs` → `assets/weapons.json`）
- **CS 原版弹道**：距离衰减 `rangeModifier^(units/500)`、穿墙公式（材质穿深/伤害修正）、弹药小数累积
- **CS2 移动手感**：64Hz 固定步长、体力跳跃（80 上限）、滑步摩擦 5.2、加速度 5.5、蹲伏spam惩罚、台阶爬升、轴分离碰撞
- **后坐力模式**：Park-Miller + Bays-Durham 洗牌 RNG（与原作 `SourceRandom` 逐位一致）生成 64 发弹匣图案
- **命中区域**：头/胸/腹/腿/颈 胶囊命中盒，爆头 4x
- **投掷物全家桶**：高爆（高斯爆炸伤害+护甲吸收）、闪光（视角+遮挡计算致盲）、烟雾（CS 视线遮挡规则 60u 偏移）、燃烧瓶/燃烧弹（范围灼烧）、诱饵弹
- **经济系统**：起始 $800 / 上限 $16000 / 连败补助 1400+500×n / 胜利 3250 / 拆弹 3500
- **规则**：冻结 6s / 回合 115s / 包 40s / 拆包 10s(5s 拆弹器)
- **地图**：de_dust2 原版真实几何体（294 个网格块，从原作 DSV1 地图数据无损转换）+ 原版烘焙光照贴图（2048² HDR DLZ1）+ 原版材质/贴图库，A/B 包点与原作同名同坐标
- **原版美术资产**：全部 41 把武器（第一人称/世界/掉落三套模型）+ T/CT 角色与手臂模型 + 700+ 张贴图，均从原作构建无损转换（DSR2 骨骼模型 → Godot 场景）

## 新增功能（原作没有的）

1. **战术 AI（行为树 + 效用系统）**：视野锥+射线遮挡感知、听声辨位（枪声 60m 传播）、烟雾遮挡判定、小队黑板共享情报、效用打分选行为（接战/找掩体/包抄/调查/撤退）、A*式 BFS 寻路、走位侧移、战术换弹
2. **Python 训练的微操策略**：CEM 交叉熵训练瞄准修正网络（奖励 -25 → -1.1，23 倍提升），权重导出 `assets/nn_policy.json`，GDScript 前向推理叠加在 bot 瞄准上。训练脚本在 `scripts/train_policy.py`，可重复训练并热替换
3. **真实音效**：从原作 1613 个 FADPCM 音频解码提取（fmod_toolkit），按声学特征分类映射到游戏事件
4. **击杀反馈**：命中标记（爆头变红骷髅）、击杀播报、伤害事件、动态准星（随精度扩散）
5. **写实画面**：体积雾 + SSAO + SDFGI 环境光遮蔽 + ACES 电影调色 + 泛光 + 战场尘雾体积块

## 工程结构

```
src/core/    确定性核心模拟（GDScript 逐文件对应 Dustline.Core）
src/game/    表现层（世界构建/HUD/音效/特效/主循环）
src/content/ 原版内容系统（材质库/烘焙光照/真实网格与模型加载）
assets/      原版地图网格与光照 / 武器角色模型 / 贴图 / 武器数据 JSON / 提取音效
scripts/     训练与转换工具（CEM 策略训练 / DSV1/DSR2 转换）
tests/       冒烟与诊断测试（godot --headless --script res://tests/smoke.gd）
```

部分音频/贴图源自原 Dustline 构建，其中可能包含 CS 系列衍生内容（已识别排除 `vistasmokev1` 等明确 Valve 资产）。若你非 Valve 授权方，**公开发布前请替换此类资产**。当前交付仅限个人研究使用。

## 已知简化

- 未移植 UDP 网络代码（GameHost/Wire/客户端预测）—— 单机 vs Bot，架构已预留（Command 驱动的确定性模拟）
- 燃烧蔓延（InfernoState 网格火）简化为定域火圈
- 动画命中盒简化为标准 CS 胶囊组（蹲伏偏移）
- 穿墙最大出口距离、跳投等细节参数与原作可能有 ±5% 偏差
